---
title: Tech stack recommendations
---

We recommend:

- [pnpm](https://pnpm.io/) for package management.
- [TanStack Router](https://tanstack.com/router) for routing.
- [shadcn/ui](https://ui.shadcn.com/) for UI components.
- [Zod](https://zod.dev/) for schemas and runtime validation.
- [@pierre/diffs](https://diffs.com/) for building custom Git diff views.

If your app already uses a different stack, follow its existing conventions.
