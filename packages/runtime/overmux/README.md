# Overmux

Overmux is a local or self-hosted web UI for terminal sessions, agents, and Git workspaces.

## Installation

Install the CLI with Mise:

```sh
mise use --global npm:overmux
```

Or with pnpm:

```sh
pnpm add --global overmux
```
