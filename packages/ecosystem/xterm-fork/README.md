# @overmux/xterm-fork

Overmux's maintained xterm.js distribution with input transformation for keyboard, text and paste, wheel magnitude handling and solid OSC 8 underlines.

- [User documentation](./docs/index.md)
- [Recipe and verification details](FORK.md)

The private workspace recipe cannot be published. Only its generated, inspected tarball is public. `6.0.0-overmux.1` is already published; future patch releases use the recipe's changeset workflow after a human verifies trusted-publisher configuration.
