---
title: Zellij (experimental)
---

<Callout type="warning">
  Experimental: compatibility is not guaranteed.
</Callout>

`@overmux/zellij` provides typed session state, targeted operations, and browser terminal streaming for Zellij 0.45.1.

Install the package in your Overmux project, then approve the bundled plugin:

```sh
pnpm add @overmux/zellij
pnpm exec overmux integration install zellij
```

See the [package README](https://github.com/richardgill/overmux/tree/main/packages/ecosystem/zellij#readme) for server and browser setup.
