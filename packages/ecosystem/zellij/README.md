# @overmux/zellij

Typed Zellij 0.45.1 state, stable targeted operations, and direct browser terminal streaming for Overmux.

> **Experimental:** compatibility is not guaranteed.

## Installation

```sh
cd ~/.config/overmux
pnpm add @overmux/zellij
pnpm exec overmux integration install zellij
```
